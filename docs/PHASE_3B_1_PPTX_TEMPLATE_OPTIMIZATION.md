# Phase 3B.1 PPTX Template Optimization

## Goal

Phase 3B.1 upgrades PPTX exports from basic text slides into a cleaner reading-report style deck. The export still uses only existing local document JSON and does not call an LLM, generate images, use animations, or depend on external templates.

## Visual Direction

- 16:9 widescreen.
- White background.
- Blue primary color.
- Light gray dividers.
- Card-based content layout.
- Larger text.
- More consistent spacing.
- Chinese-friendly reading density.
- Suitable for document interpretation reports.

## Template Structure

The PPTX exporter now uses shared layout helpers:

- `addSlideTitle`
- `addFooter`
- `addCard`
- `addTagList`
- `splitIntoSlides`
- `truncateText`

Each content slide has a consistent title area, divider line, page footer, and `DocuMuse` footer mark.

## Slide Types

- Cover: stronger title treatment, report subtitle, metadata card, and pale-blue decorative panel.
- Summary: one card for one-sentence summary and one larger card for full summary.
- Key Points: two-column cards with numbered labels.
- Keywords: badge/tag layout.
- Section Analysis: one to two section cards per page.
- PPT Outline: slide-card layout with up to three outline cards per page.
- Podcast Script: separate page with a short excerpt.
- Image Prompts: prompt cards, up to three per page, text only.
- Document Q&A: up to two recent Q&A rounds per page with short source hints.
- Closing: centered `Generated by DocuMuse` ending page.

## Pagination

Long collections are split into multiple slides:

- Section Analysis: 2 sections per slide.
- PPT Outline: 3 outline cards per slide.
- Image Prompts: 3 prompt cards per slide.
- Document Q&A: 2 Q&A rounds per slide, using the most recent 5 rounds.

## Truncation Strategy

Text is truncated before being placed into slides to avoid overfilled pages:

- Key points: about 135 characters.
- Section summaries: about 245 characters.
- PPT outline bullets: about 90 characters.
- Podcast excerpt: about 800 characters.
- Image prompts: about 220 characters.
- Q&A answers: about 235 characters.
- Source quotes: about 95 characters.

Truncated text uses `…`.

## Security

PPTX export still excludes:

- API keys.
- Full prompts.
- Raw model output.
- Full `document.text`.
- `analysisDiagnostics.rawPreview`.
- `data/settings`.
- Absolute upload paths.
- Full chunk text.

## Current Limits

- No external template files.
- No generated images.
- No animations.
- No speaker notes.
- No brand/theme editor yet.
- The layout is intentionally simple and conservative.

## Validation

The optimized PPTX route was validated through the built Next.js route handler:

- Status `200`.
- PPTX MIME type.
- `Content-Disposition` attachment filename.
- ZIP/PPTX magic header `504b0304`.
- Contains `ppt/presentation.xml`.
- No detected API key-like strings or sensitive field names.
- No detected `undefined`, `null`, or `[object Object]` in generated binary text scan.
