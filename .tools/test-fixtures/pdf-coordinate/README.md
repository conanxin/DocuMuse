# PDF Coordinate Fixtures

This directory contains small local PDFs used to validate DocuMuse PDF coordinate extraction and preview overlay behavior.

Keep fixtures small. Do not add large, proprietary, or externally downloaded PDFs.

## Manifest

Fixture metadata lives in:

```text
manifest.json
```

`active` fixtures are required to pass `npm run test:pdf-coordinates`.

`pending` fixtures document important scenarios that are not covered yet. They do not fail the test.

## Active Fixtures

### `simple-one-page.pdf`

- Source: copied from `.tools/test-fixtures/text.pdf`.
- Purpose: baseline selectable-text PDF for coordinate extraction, paragraph mapping, and overlay smoke tests.
- Expected behavior:
  - `pdfjs-dist` can extract text items.
  - at least one paragraph position can be generated.
  - at least one bounding box is finite and positive.

### `simple-multipage.pdf`

- Source: generated by `.tools/scripts/generate-pdf-coordinate-fixtures.mjs`.
- Purpose: page number extraction, page navigation, and source-page routing.
- Expected behavior:
  - at least 3 pages.
  - text items appear on multiple pages.
  - paragraph-like text items generate page-aware bounding boxes.

### `dense-paragraphs.pdf`

- Source: generated by `.tools/scripts/generate-pdf-coordinate-fixtures.mjs`.
- Purpose: paragraph mapping across many text blocks.
- Expected behavior:
  - many text items are extracted.
  - multiple paragraph positions can be generated.

### `two-column.pdf`

- Source: generated by `.tools/scripts/generate-pdf-coordinate-fixtures.mjs`.
- Purpose: lightweight two-column layout coverage.
- Expected behavior:
  - text items are extracted from a CSS column layout.
  - bounding boxes remain finite and positive.

## Generate Fixtures

Run:

```bash
npm run generate:pdf-coordinate-fixtures
```

The generator uses local Microsoft Edge headless printing. It does not use external services or download resources.

## Validate Fixtures

Run:

```bash
npm run test:pdf-coordinates
```

Current expected summary:

```text
4 passed, 3 pending, 0 failed
```

## Not Covered Yet

- True rotated PDF page dictionaries.
- CropBox / MediaBox mismatch.
- Mixed page sizes.
- Scanned PDFs without selectable text.
- Image-heavy PDFs.
- Table-heavy PDFs.

These cases should be added in later coordinate regression phases.
