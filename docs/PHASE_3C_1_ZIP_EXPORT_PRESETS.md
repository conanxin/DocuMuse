# Phase 3C.1 ZIP Export Presets

## Goal

Phase 3C.1 changes export presets from browser multi-file downloads to a single ZIP download generated on the server.

This reduces browser multi-download blocking while preserving all existing single-file exports.

## Dependency

ZIP generation uses:

```text
jszip
```

The ZIP is generated in memory. No temporary files are written and no external service is used.

## API

New route:

```text
GET /api/documents/[id]/export/preset?preset={presetId}
```

Supported presets:

- `study-notes`
- `presentation-pack`
- `research-digest`
- `podcast-prep`
- `full-archive`

Successful responses return:

```text
Content-Type: application/zip
Content-Disposition: attachment; filename="documuse-{safe-title}-{preset}.zip"
```

Invalid presets return JSON `400`. Missing documents return JSON `404`.

## ZIP Contents

Depending on preset, the ZIP can include:

- `documuse-report.md`
- `documuse-data.json`
- `documuse-slides.pptx`
- `documuse-chat.md`
- `README.txt`

`README.txt` includes preset name, document title, export time, file list, and `Generated by DocuMuse`.

## Reused Exporters

ZIP generation reuses existing exporters:

- `buildDocumentMarkdownExport`
- `buildDocumentJsonExport`
- `buildDocumentPptxExport`
- `exportPresets`

## Frontend

The `导出预设` dialog now downloads one ZIP per preset. The card button label is `下载 ZIP`.

If ZIP download fails, the UI suggests using existing single-file export buttons as a fallback.

## Phase 3C.1 Hotfix

The preset export dialog loading state now tracks the active `presetId`.

When one preset is downloading:

- Only that preset button shows `正在下载...`.
- Other preset buttons are disabled but still show `下载 ZIP`.
- The active preset id is cleared after success or failure.

## Security

ZIP files do not include:

- API keys.
- Prompts.
- Raw model output.
- Full original document text.
- `data/settings`.
- Absolute upload paths.
- `analysisDiagnostics.rawPreview`.
- Full chunk text.

## Current Limits

- ZIP generation is in-memory.
- No cloud sync.
- No saved custom user presets.
- No user-selected ZIP file list yet.
- Demo documents do not use real ZIP preset export.
