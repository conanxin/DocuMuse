# Phase 3B PPTX Export

## Goal

Phase 3B adds a real `.pptx` export path for DocuMuse. The export is generated from existing local document JSON only. It does not call an LLM, generate images, create audio, use embeddings, or access external services.

## Dependency

PPTX generation uses:

```text
pptxgenjs
```

## API

Existing export route now supports:

```text
GET /api/documents/[id]/export?format=pptx
```

Successful responses return:

```text
Content-Type: application/vnd.openxmlformats-officedocument.presentationml.presentation
Content-Disposition: attachment; filename="documuse-xxx.pptx"
```

Missing documents return JSON `404`. Unsupported formats return JSON `400`.

## Generated Slides

The PPTX export includes:

1. Cover slide with document title, filename, export time, provider, model, and `Generated by DocuMuse`.
2. 摘要 slide with one-sentence summary and a shortened full summary.
3. 核心观点 slides with numbered two-column cards.
4. 关键词 slide with tag-style badges.
5. 分段分析 slides with knowledge-card summaries.
6. PPT 大纲 slides with outline cards.
7. 播客脚本 slide with a short script excerpt.
8. 图片提示词 slides with text prompts only.
9. 文档问答 slides with recent question-answer rounds and separated source quotes.
10. Closing slide.

## Visual Style

- 16:9 widescreen.
- White background.
- Blue section titles.
- Modern reading-report layout with card-based sections.
- Consistent footer and page numbering.
- Larger headings and more comfortable spacing.
- No external fonts.
- No external images.
- No animations.
- Long text is truncated to avoid overfilled slides.

Phase 3B.1 adds a reusable in-code template layer for cover, summary, key points, keywords, section analysis, outline, creative output, Q&A, and closing slides.

Phase 3B.1.1 applies real export feedback: Chinese-first slide titles, row-based cover metadata, stricter text cleaning, shorter summary and section excerpts, paragraph-style podcast excerpts, and less dense Q&A slides.

Local WPS / PowerPoint validation has passed for the Phase 3B.1.1 template. The current PPTX export status is: basic deliverable usable.

## Security Filtering

The PPTX export does not include:

- API keys.
- Full prompts.
- Raw model output.
- Full `document.text`.
- `analysisDiagnostics.rawPreview`.
- `data/settings`.
- Absolute upload paths.
- Full chunk text.

The PPTX may include:

- Document filename and title.
- Provider and model names.
- Summaries and key points.
- Section summaries.
- Existing PPT outline.
- Existing podcast script excerpt.
- Existing image prompt text.
- Short chat Q&A excerpts and source quotes.

## Current Limits

- No user-editable template system.
- No brand theme switching.
- No export section picker.
- No image generation.
- No inserted generated images.
- No speaker notes.
- No animations or transitions.
- No complex template editor.
- No full source text export.
- Layout is intentionally simple and conservative.

## Future Work

Future work can add brand themes, richer slide layouts, user-selected sections, and optional speaker notes.
